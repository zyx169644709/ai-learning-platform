# 仪表盘数据计算说明

> 数据来源：`GET /admin/stats` 后端接口 + 前端二次计算  
> 后端代码：`server/src/controllers/adminController.ts → getStats()`  
> 前端代码：`admin/src/pages/admin/Dashboard.vue → loadDashboardData()`

---

## 一、顶部四个卡片

### 1. 今日新增用户 `+N`
| 项目 | 说明 |
|------|------|
| **数值** | 今日 00:00 ~ 23:59 内 `createdAt` 落在该范围的用户数 |
| **趋势箭头** | `(今日数 - 昨日数) / 昨日数 × 100%`；昨日为 0 且今日 > 0 时显示 `+100%` |
| **数据源** | 后端 `prisma.user.count({ where: { createdAt: { gte: todayStart, lte: todayEnd } } })` |

---

### 2. 今日新增内容 `+N`
| 项目 | 说明 |
|------|------|
| **数值** | 今日 00:00 后 **更新或创建** 的课程 + 资源 + 章节 数量之和 |
| **趋势箭头** | `(今日数 - 昨日数) / 昨日数 × 100%` |
| **数据源** | 前端对拉取到的全量课程/资源/章节列表，按 `updatedAt ?? createdAt >= 今日00:00` 过滤后计数 |
| **注意** | 以 `updatedAt` 优先，字段不存在时退回 `createdAt` |

---

### 3. 待审核内容 `N`
| 项目 | 说明 |
|------|------|
| **数值** | `status === 'pending'` 的讨论数 + 评论数 |
| **状态标签** | `> 5` 显示「需处理」（红色），否则「正常」 |
| **数据源** | 前端从拉取的全量讨论/评论中过滤 `status === 'pending'` |

---

### 4. 用户活跃度 `N%`
| 项目 | 说明 |
|------|------|
| **数值** | DAU / MAU × 100，取整 |
| **DAU** | 今日 00:00 ~ 23:59 内有 `lastLoginAt` 更新的用户数 |
| **MAU** | 近 30 天内有 `lastLoginAt` 更新的用户数 |
| **标签** | `≥ 50%` → 优秀；`≥ 30%` → 良好；`≥ 10%` → 一般；`< 10%` → 较低 |
| **数据源** | 后端 `countUsersActiveInRange()` 查询 `lastLoginAt` 范围 |

---

## 二、右侧内容质量指标（近 30 天）

> 所有指标均基于过去 30 天的数据计算，显示为 0~100 的进度条。

### 1. 平均小节完成率
```
近 30 天内创建的 SectionCompletion 记录总数
─────────────────────────────────────────── × 100
           已发布小节（type='section'）总数
```
| 字段 | 含义 |
|------|------|
| 分子 | `prisma.sectionCompletion.count({ where: { completedAt: { gte: 30天前 } } })` |
| 分母 | `prisma.chapter.count({ where: { type: 'section', status: 'published' } })` |

---

### 2. 用户活跃度
```
今日活跃用户数（DAU）
──────────────────── × 100
近 30 天活跃用户数（MAU）
```
> 与顶部卡片第 4 项计算逻辑完全相同，同样使用 `lastLoginAt` 判断活跃。

| 标签阈值 | 说明 |
|----------|------|
| `≥ 50` | 优秀 |
| `≥ 30` | 良好 |
| `≥ 10` | 一般 |
| `< 10` | 较低 |

---

### 3. 讨论互动率
```
(近 30 天讨论点赞总数 + 近 30 天评论点赞总数)
─────────────────────────────────────────────── × 10，上限 100
             近 30 天讨论帖子总数
```
| 字段 | 含义 |
|------|------|
| 讨论点赞 | `discussion.aggregate({ _sum: { likes } })` |
| 评论点赞 | `comment.aggregate({ _sum: { likes } })` |
| 讨论总数 | `discussion.aggregate({ _count: { id } })` |
| 系数 `×10` | 每个帖子平均 10 个点赞时达到 100%，防止大多数项目中该值过小 |

---

### 4. 资源收藏率
```
已发布资源 favoriteCount 总和
─────────────────────────────── × 100
已发布资源 viewCount 总和
```
| 字段 | 含义 |
|------|------|
| 数据范围 | `status = 'published'` 的全部资源（不限 30 天） |
| 分子 | `resource.aggregate({ _sum: { favoriteCount } })` |
| 分母 | `resource.aggregate({ _sum: { viewCount } })` |
| 为 0 时 | 分母为 0 则返回 0% |
