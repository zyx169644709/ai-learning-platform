# Vue 3 简介与环境搭建

Vue (发音为 /vjuː/，类似 **view**) 是一款用于构建用户界面的 JavaScript 框架。它基于标准 HTML、CSS 和 JavaScript 构建，并提供了一套声明式的、组件化的编程模型，帮助你高效地开发用户界面。

## 为什么选择 Vue 3？

- **组合式 API (Composition API)**：更好的逻辑复用和代码组织。
- **更快的性能**：更小的打包体积和更优的虚拟 DOM。
- **更好的 TypeScript 支持**：原生支持，类型推导更精准。
- **庞大的生态系统**：如 Vite, Pinia, Vue Router 等。

## 环境搭建

### 1. 安装 Node.js
确保你安装了最新的 LTS 版本。

### 2. 创建一个 Vue 应用
使用 Vite 快速启动：

```bash
npm create vue@latest
```

按照提示选择功能，然后：

```bash
cd <your-project-name>
npm install
npm run dev
```

### 3. 开始你的 Vue 之旅！
现在，你可以打开浏览器访问 `http://localhost:5173` 查看你的第一个 Vue 3 项目。
