# Vue 3 基础语法练习题

通过以下习题巩固你对 Vue 3 基础语法的理解。

## 练习 1：响应式基础
请编写一个简单的计数器组件，包含一个数字显示和两个按钮（增加、减少）。要求使用 `ref()` 定义状态。

## 练习 2：模板指令
给定一个水果列表数组，请使用 `v-for` 将其渲染为无序列表，并根据水果的库存状态（isAvailable）使用 `v-if` 或 `v-show` 显示“有货”或“无货”。

## 练习 3：计算属性
创建一个包含姓（firstName）和名（lastName）的表单输入框，并使用 `computed` 实时显示全名。

## 练习 4：监听器
编写一个搜索框，使用 `watch` 监听输入内容的变化，并在控制台打印当前的搜索关键词。
