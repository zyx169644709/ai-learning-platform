# 组件设计模式练习

提升你的 Vue 3 组件设计能力，学习如何构建可维护、可扩展的组件。

## 练习 1：无渲染组件 (Renderless Components)
尝试编写一个处理“点击外部关闭”逻辑的无渲染组件。它应该只负责逻辑，通过作用域插槽将状态和行为传递给父组件。

## 练习 2：复合组件 (Compound Components)
仿照 UI 库（如 Element Plus），设计一个 Select 组件系统，包含 `Select` 和 `Option` 两个组件，它们之间通过 `provide/inject` 进行通信。

## 练习 3：高阶组件与插件
编写一个简单的 Vue 插件，为所有组件实例注入一个全局的 `$log` 方法。

## 练习 4：组合式函数 vs Mixins
将一段旧的 Mixin 逻辑（如：窗口大小调整追踪）重构为一个清晰的组合式函数 (Composable)。

---
**提示**：优秀的组件设计应该遵循“高内聚、低耦合”的原则。
