# 深入组件系统

掌握 Vue 组件系统的高级特性，构建复杂且高性能的应用。

## 学习目标

- 深入理解组件 Props 的高级声明与校验。
- 掌握自定义事件与组件 `v-model` 的实现。
- 全面了解插槽 (Slots) 的各种用法（默认、具名、作用域）。
- 学习如何使用异步组件与 `Teleport` 解决实际问题。

1. [组件注册与属性 Props](props-registration)
2. [自定义事件与 v-model](events-vmodel)
