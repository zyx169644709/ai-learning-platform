# Composition API 进阶

组合式 API (Composition API) 是 Vue 3 的核心特性，它为逻辑复用和代码组织提供了全新的方式。

## 学习目标

- 掌握 `setup()` 函数及其语法糖 `<script setup>`。
- 学习如何编写和使用组合式函数 (Composables)。
- 理解依赖注入 `provide` 和 `inject` 的高级用法。
- 掌握模板引用 (Template Refs) 与复杂的组件通信。

1. [Setup 函数与生命周期钩子](setup-lifecycle)
2. [逻辑复用：Composables](composables)
3. [依赖注入：Provide / Inject](provide-inject)
4. [Template Refs 与组件通信](refs-communication)

通过本章的学习，你将能够以更灵活、更可维护的方式编写 Vue 组件。
