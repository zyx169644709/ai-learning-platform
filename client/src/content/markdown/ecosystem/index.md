# Vue 生态与工程化

Vue 拥有一个庞大且活跃的生态系统，提供了从开发到部署的全方位支持。

## 核心库

- **Vue Router**: 官方路由管理器，用于构建单页面应用。
- **Pinia**: 官方状态管理库，简洁、类型安全且易于测试。
- **Vue DevTools**: 浏览器扩展，提供强大的调试功能。

## 构建工具

- **Vite**: 下一代前端开发与构建工具，以极速著称。
- **Vue CLI**: 基于 Webpack 的传统构建工具（目前推荐使用 Vite）。

## UI 组件库

- **Element Plus**: 专业的 Vue 3 组件库，适用于后台管理系统。
- **Ant Design Vue**: 企业级 UI 设计体系的 Vue 实现。
- **Naive UI**: 极其完整、可高度自定义、使用 TypeScript 编写的组件库。
- **Vant**: 轻量、可靠的移动端 Vue 组件库。

## 测试工具

- **Vitest**: 由 Vite 驱动的极速单元测试框架。
- **Vue Test Utils**: Vue 组件测试的官方底层库。
- **Cypress**: 强大的端到端 (E2E) 测试框架。

## 实用工具

- **VueUse**: 组合式 API 的工具函数集合。
- **Vue Macros**: 探索性提案的宏集合，增强 Vue 开发体验。
