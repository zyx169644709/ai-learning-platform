# 项目实战：后台管理系统 (Admin System)

这是一个综合性项目，要求你整合 Vue 3 的大部分核心技术，模拟真实的企业级应用开发。

## 学习目标

- 整合 Pinia 进行复杂的用户状态与权限管理。
- 使用 `vue-router` 实现基于权限的动态路由。
- 学习如何封装通用的 UI 组件（如 Table, Form, Dialog）。
- 实践大规模应用的代码组织与模块化。
- 掌握如何与后端 API 进行完整的交互与错误处理。

## 功能要求

1. **登录与权限控制**：根据用户角色显示不同的侧边栏菜单。
2. **数据仪表盘**：使用图表库（如 ECharts）展示统计数据。
3. **资源管理**：实现对数据的增删改查 (CRUD) 操作。
4. **主题切换**：支持深色/浅色模式。
5. **面包屑导航**：自动生成的导航路径。

## 技术栈推荐

- **框架**：Vue 3 (Composition API)
- **状态管理**：Pinia
- **路由**：Vue Router 4
- **UI 组件库**：Element Plus 或 Ant Design Vue
- **图表**：ECharts
- **构建工具**：Vite

---
**提示**：你可以从封装一个带有全选功能的通用数据表格开始。
