# 实战项目演练

通过参与真实的项目开发，将所学的 Vue 3 理论知识转化为实际的编程技能。

## 项目列表

在本章节中，我们将通过以下三个由浅入深的项目进行练习：

1. [项目实战：待办事项清单 (TodoList)](project-todolist) - 掌握基础指令、双向绑定与组件通信。
2. [项目实战：个人博客系统 (SPA)](project-blog) - 实践 Vue Router 路由管理与异步数据交互。
3. [项目实战：后台管理系统 (Admin System)](project-admin) - 综合应用 Pinia 状态管理、组件封装与企业级应用架构。

## 学习建议

- **动手尝试**：不要只阅读文档，请务必在本地环境或本平台的在线编辑器中手动编写代码。
- **由易到难**：建议按照顺序完成项目，每个项目都会在前一个项目的基础上增加新的技术挑战。
- **查阅文档**：在开发过程中，随时查阅 Vue 官方文档是专业开发者的必备技能。
