# 项目实战：待办事项清单 (TodoList)

待办事项清单是学习任何前端框架的最佳入门项目。通过本项目，你将练习 Vue 3 的核心概念。

## 学习目标

- 熟练使用 `v-model` 处理表单输入。
- 练习 `v-for` 列表渲染及其 `key` 的重要性。
- 使用 `computed` 实现任务过滤（全部/已完成/未完成）。
- 掌握组件间通信（Props 与 Emits）。
- 了解本地存储（localStorage）的集成。

## 功能要求

1. **添加任务**：输入文本并按回车或点击按钮添加。
2. **列表显示**：展示所有任务，支持勾选完成。
3. **删除任务**：点击任务旁的删除按钮移除。
4. **状态过滤**：底部提供切换按钮，过滤显示不同状态的任务。
5. **数据持久化**：刷新页面后数据不丢失。

## 推荐组件结构

- `App.vue`：管理整体状态。
- `TodoInput.vue`：负责输入逻辑。
- `TodoList.vue`：负责渲染列表。
- `TodoItem.vue`：单个任务项及交互。
- `TodoFilter.vue`：底部过滤工具栏。
